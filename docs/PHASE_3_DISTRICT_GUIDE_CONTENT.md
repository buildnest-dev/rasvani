# Phase 3 — Evidence-reviewed district guide content

## Delivered
- Added optional concise district introduction (maximum 500 characters).
- Added optional food-heritage context (maximum 2,000 characters).
- Both fields are saved with the district evidence reference and remain draft-only until the normal regional quality-review workflow approves the district.
- The reviewer queue now displays the exact proposed guide copy alongside its evidence reference.
- Public district pages render only approved district guide copy and approved food associations.
- No district examples, foods, heritage facts or origin claims are seeded.

## Governance
The same evidence reference is the review packet reference for the district guide. Reviewers must inspect it and approve/reject the full proposed record. If separate evidence is needed for individual statements, record it in the referenced evidence packet or leave the optional text blank.
